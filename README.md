# SVG PowerPoint Studio — integrated single-app edition

A single Flask application that creates presentation outlines, generates slide content, creates SVG illustrations, previews slides, and exports PowerPoint files. **There is no separate SVG Visual Studio server or second Flask application to run.** Both slide-content generation and SVG illustration generation call the same configured Ollama instance directly from `app.py`.

## Workflow

1. Enter a topic, audience, slide count, and instructions.
2. Generate the slide outline.
3. Review and edit slide titles, purposes, key points, visual prompts, and suggested layouts.
4. Approve the outline to generate full slide content.
5. For slides marked visual-needed, this app generates SVG shape data through Ollama and renders it in the preview.
6. Refine any slide: change its layout, regenerate its content, or regenerate its SVG illustration with a new prompt.
7. Export the deck as `.pptx`.

## Dedicated composition layouts

- **Text Only** — content across the slide, no image.
- **Image Only** — large SVG illustration.
- **Text + Image (Image Left)** — image on the left, text on the right.
- **Text + Image (Image Right)** — text on the left, image on the right.
- **Text + Image (Image Top)** — image above concise text.
- Plus agenda, title hero, section divider, columns, comparison, process, timeline, architecture, SWOT, pyramid, summary, and other layouts.

Selecting an image layout marks the slide as visual-required. The app generates the SVG using the selected slide's visual prompt, or creates a prompt from its title and content. SVG generation errors are shown in the preview and can be retried.

## Architecture

```text
Browser (HTML/CSS/JavaScript)
          |
          v
   One Flask app (app.py)
       |           |
       v           v
 Ollama chat    SVG shape JSON
 slide content  generated by Ollama
       |           |
       +-----+-----+
             v
     SVG preview renderer
             |
             v
     PowerPoint exporter
```

The SVG illustrations are converted to PNG for insertion into PPTX to maximize PowerPoint compatibility. Slide text and native PowerPoint shapes remain editable; the embedded illustration itself is an image.

## Requirements

- Python 3.10+
- Ollama running locally or reachable over the network
- The configured Ollama model pulled and available

## Windows setup

Only this application needs to be started:

```powershell
cd svg_ppt_studio
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
python app.py
```

Open `http://127.0.0.1:8100`.

Configure `.env`:

```env
OLLAMA_URL=http://localhost:11434
OLLAMA_MODEL=qwen2.5:14b
PORT=8100
EXPORT_DIR=exports
```

To use another model, change `OLLAMA_MODEL` to a model available in your Ollama installation. The same model is used for slide outlines, slide content, slide regeneration, and SVG illustrations.

## API endpoints

- `GET /api/health` — checks Ollama connectivity and reports the configured model.
- `GET /api/catalog` — returns available themes and layouts.
- `POST /api/generate-outline` — generates the outline for review.
- `POST /api/generate-content` — expands the approved outline into slide content.
- `POST /api/regenerate-slide` — regenerates one slide's content.
- `POST /api/generate-visual` — generates SVG shape data directly with Ollama inside this Flask app; no external SVG endpoint is called.
- `POST /api/export-pptx` — exports the selected theme, layouts, content, and illustrations to PPTX.

## Important notes

- Ollama must be running and the selected model must be available. The app returns a visible error when generation fails rather than silently substituting generic content.
- The Data/Chart layout is illustrative; it must not be treated as measured data unless real values are provided.
- SVG illustrations are generated from structured shape data. They are not raster image-generation-model outputs or photographs.
